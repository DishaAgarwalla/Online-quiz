An interactive **Online Quiz Application** built using **HTML, CSS, and JavaScript**.  
This app allows users to attempt multiple-choice questions, get instant feedback, and view their final score at the end of the quiz.

---

## 🚀 Features

- ❓ Multiple-choice questions
- ⏱️ Instant answer validation
- 🏆 Score calculation system
- 🔄 Restart quiz option
- 🎯 Clean and user-friendly UI
- 📱 Fully responsive design

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
